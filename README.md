# Personal-expense-tracker
A Python-based personal expense tracker to record, categorize, and analyze daily expenses.

## Project Description
This is a beginner-friendly Python project that helps users manage their daily expenses and calculate their total spending.

## Features
- Enter expense names.
- Enter expense amounts.
- Display all entered expenses.
- Calculate total expenses.

## Technologies Used
- Python
- Spyder IDE
